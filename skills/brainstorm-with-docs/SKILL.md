Call the Skill tool twice, for "brainstorm" and "domain-modeling". Run the brainstorm rounds as written. Each domain-modeling challenge (a conflicting or fuzzy term, an edge-case scenario, a contradiction with the code) enters the current round as a frontier question, and the glossary and ADR writes happen as its answers settle them.
